# Kit di B-roll

Progetto [Remotion](https://www.remotion.dev) con le grafiche riutilizzabili: componenti in `src/kit/components.tsx`, colori e font in `src/kit/theme.ts`, formati in `src/Root.tsx`.

Anteprima:

```bash
npm run dev
```

Render di una grafica:

```bash
npx remotion render Diagram out/diagram.mp4
```

Remotion ha [condizioni proprie](../THIRD-PARTY-NOTICES.md): è gratuito per privati e per aziende fino a 3 dipendenti.
